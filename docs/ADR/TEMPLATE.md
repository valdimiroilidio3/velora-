# ADR NNNN — Título curto (decisão X porque Y)

- **Estado**: Proposto | Aceite | Implementado | Substituído por ADR-MMMM | Rejeitado
- **Data**: AAAA-MM-DD
- **Impacto de fase**: Fase N
- **Decisão tomada por**: (humano/agente + revisão de quem)

## Contexto

Que força nos obriga a decidir? Que requisito aprovado ou que bloqueio gerou esta questão?
Que alternativas já falharam ou foram descartadas antes daqui.

## Decisão

Uma frase afirmativa. Depois os detalhes verificáveis (versões, comandos, ficheiros alterados).

## Alternativas consideradas

| Alternativa | Porque não |
| ----------- | ---------- |
|             |            |

## Consequências

- Positivas (mensuráveis, com evidência quando existir).
- Negativas/aceites (o que passamos a ter de viver com isto).
- O que **deixa de ser possível** sem novo ADR (decisões travadas deliberadamente).

## Verificação

Qual o comando/teste que prova que a decisão está implementada, e qual foi o resultado observado.
Sem isto, fica "Aceite", não "Implementado".

## Reversão

Como se desfaz, quanto custa, e se há dados a mover.
